# Товар котормолорун текшерүү жана бекитүү

product-translations-draft.json — 275 товар үчүн гана сунушталган котормолор. Ар бир жазуу approved: false; файл MongoDB'ге автоматтык колдонулбайт. Товарлар коомдук GET API аркылуу гана окулду. 22 кайталанбаган аталыш, 22 сүрөттөмө жана 3 категория которулду. Ингредиент, фирмалык аталыш жана тилдин табигыйлыгын ресторан администратору текшериши керек.

## Колдонуу

1. Жаңы backend жана frontend чогуу иштетилгенден кийин админге кириңиз. Бул өзгөртүүлөр азыр deploy болгон жок.
2. Товарлар бөлүмүнөн бир товарды «Өзгөртүү» менен ачыңыз. Баштапкы аталыш/категория/баа/варианттар өзүнчө сакталат.
3. «Котормо долбоорун ачуу» аркылуу JSON файлды тандаңыз. Тандалган товар ID'си, баштапкы талаалар, баа/сүрөт жана вариант ID/маанилери учурдагы API менен салыштырылат. Эскирген долбоор кабыл алынбайт.
4. Кыргызча, Русский, English, Türkçe өтмөктөрүнөн ар бир аталышты, сүрөттөмөнү, категорияны жана вариантты карап түзөтүңүз. Бош талаа — котормо жок дегенди билдирет.
5. «Сунушталган котормолорду текшердим жана бекитем» белгисин коюңуз. Ушуга чейин эч бир API жазуу операциясы жок.
6. «Котормолорду гана сактоо» баскычын басыңыз. Ал JWT/admin коргоосундагы PATCH /api/products/:id/translations маршрутун чакырат. Endpoint котормо талааларын гана өзгөртө алат; баа/сүрөт/түпнуска вариант/ID өзгөрбөйт. Башка тилдин берилбеген талаалары сакталат.
7. Кардар менюсунан ошол товарды 4 тилде текшериңиз. Категориялар өзүнчө коллекция эмес; category техникалык сап бойдон калат, translations.<lang>.category көрүнгөн энбелги болот.

Жапырт импорттоочу же MongoDB'ге автоматтык жазуучу скрипт кошулган жок. Ар бир товарды өзүнчө текшерип сактоо керек. Учурдагы/жаңы товарды кадимки сактоо да баштапкы форма менен төрт тилдеги маалыматты жөнөтөт. Котормолорду гана жаңыртуу үчүн атайын баскычты колдонуңуз.

## Формат

translations: { ky: { name, description, category }, ru: {...}, en: {...}, tr: {...} }
options[].translations: { en: { name, values: [{ value: '0.3 л', label: '0.3 L' }] }, ... }

values[].value — өзгөрбөгөн техникалык маани; label гана котормо. Маанилер массив катары сакталат, анткени «0.3 л» сыяктуу чекиттүү текст MongoDB Map ачкычы катары жарабайт. Кардар мурдагы объект түрүндөгү котормолорду да окуй алат.
