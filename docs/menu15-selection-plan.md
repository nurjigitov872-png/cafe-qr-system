# 15 товарлык меню: тандоо планы жана алдын ала көрүнүш

Бул долбоор MongoDB'ге колдонулган жок. Бардык 15 ID, баа, сүрөт жана варианттар учурдагы коомдук API'ден окулду. Котормолор сунуш гана; approved: false. Калган 260 товар өчүрүлбөйт жана кадимки менюда калат.

Каталогдо үч гана өзгөчө десерт аталышы бар. Беш десерт позициясы үчүн үч башка учурдагы балмуздак ID'си колдонулду. Алар жаңы десерт болуп көрсөтүлбөйт: карточканын аталышы «Балмуздак», ал эми ваниль/шоколад/кулпунай учурдагы вариант катары көрсөтүлөт. Десерттердин беш башка түрү керек болсо, администратор кошумча эки товарды өзүнчө бекитиши керек.

## Коопсуз localhost preview

Frontend dev сервери иштеп турганда: http://localhost:5173/table/1?preview=menu15

Бул режим localhost/127.0.0.1 жана Vite development үчүн гана иштейт. Production build'де query параметри режимди жандырбайт. Себетти жана тил/теманы текшерүүгө болот; «Заказды ырастоо» браузерде гана mock checkout аткарат; реалдуу API/MongoDB/Telegram/төлөм суроолору жок. Официант чакыруу жабык. Тесттик ийгилик барагы ачык түрдө симуляция экенин билдирет.

Алдын ала көрүнүш учурдагы API баа/сүрөт/аталыш/категория/вариант маанилерин кайра салыштырат. Товар өзгөрсө, жоголсо же жеткиликсиз болсо, аны жалган эски маалымат менен көрсөтпөйт. Айрым эски товарлардын вариант ID'лери API окуусунда кайра түзүлгөнү байкалды; preview аларды өзгөртпөй, учурдагы жооптогу ID'лерди сактайт жана аталыш/маанилердин дал келишин текшерет. Базага ID оңдоосу жүргүзүлгөн жок.

## Кийинки бекитүү

1. frontend/src/data/menu15-draft.json ичиндеги 15 ID, баа, сүрөт жана 4 тилдеги текстти караңыз.
2. Localhost preview'ду бекитиңиз. Кадимки менюга кайтуу үчүн ?preview=menu15 параметрин алып салыңыз.
3. Өндүрүштө 15 товарды гана көрсөтүү өзүнчө бекитүүдөн кийин туруктуу allowlist аркылуу ишке ашырылат; калган товарларды өчүрүү талап кылынбайт. Бул иш азыр жасалган жок.
4. Котормолорду сактоо үчүн мурда даярдалган админдин котормо редактору/өзүнчө котормо PATCH колдонулат, ар бир товар администратор тарабынан текшерилет. Preview JSON автоматтык MongoDB импорту эмес.

## Mock checkout

Товарларды, бардык варианттарды, санды, заказ түрүн жана төлөм ыкмасын тандаңыз. «Заказды ырастоо» столдун оң бүтүн сан экенин, товар/баанын менюга дал келишин, варианттардын жарактуулугун жана сумманы текшерет. Туура эмес болсо себетте түшүндүрмө чыгат. Туура болсо өзүнчө симуляция көрүнүшү ачылат. Ал реалдуу заказ ID/токенин же localStorage заказ белгилерин түзбөйт. «Preview себетине кайтуу» тандалган товарларды сактайт. Кадимки checkout бутактары өзгөрбөйт.
